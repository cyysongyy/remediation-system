☁️ 雲端後台（Ybot Apps Script）
城市名稱即可（例如「台北」「高雄」），用於首頁天氣與每日簡報，預設台北。
設定後可：待辦／提醒同步雲端、彙整 Gmail 未讀信與日曆行程、每日 7 點自動寄「Ybot 每日簡報」、提醒到點主動寄信。
部署步驟：開一份 Google 試算表 → 擴充功能 → Apps Script → 貼上 ybot-backend.gs → 執行一次 setupDailyBrief()、setupReminderWatch()、setupEveningDigest() 授權 → 部署為網頁應用程式（執行身分：我；存取：所有人）→ 複製網址貼在這裡。每日簡報會依🔴今天必須／🟠建議今天／🟢可延後分級；晚間彙整只在還有未處理的🔴🟠事項時才會寄信，平時不打擾。
🔗 整合其他系統
填入其他兩套系統的 Apps Script 後台網址，Ybot 對話與每日簡報就能一併帶入考卷批改與健康預測的最新摘要。
🔗 我的其他 App
你在 GitHub 上的其他自建 App，可在對話中快速開啟、也讓 Ybot 知道它們存在。若該 App 有自己的 Apps Script 後台網址，填入「後台網址」欄位，Ybot 每日簡報與對話會一併嘗試帶入其摘要（讀不到會自動略過）。
