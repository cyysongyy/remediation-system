## 🔍 考卷審題框架（理論依據）

「🔍 考卷審題」功能會依教育測驗與評量核心理論，對**空白考卷**做系統化檢核。原則已寫入程式碼（`index.html` 中的 `REVIEW_PRINCIPLES` 知識庫）作為審題單一事實來源，並帶入 AI prompt。

**理論基礎**：內容效度與雙向細目表 · Bloom 認知層次（記憶→了解→應用→分析→評鑑→創作）· 古典測驗理論（難易度／鑑別度／信度，理想難易約 3:5:2 或 2:6:2）· 素養導向評量（108 課綱）。

其中三項理論會化為每份考卷的**獨立分析區塊**（畫面與匯出檢核表皆呈現）：

| 分析 | 產出 |
|---|---|
| 🧠 **Bloom 認知層次分布** | 依「記憶→了解→應用→分析→評鑑→創作」估算六層次題數比例並繪成分布條，評論是否符合該年級（低年級記憶理解較高、高年級提升應用分析），避免整卷死記硬背 |
| 🌱 **素養導向評量** | 判定整卷情境化／整合運用／跨領域程度（明確／部分／多為套公式），並點名脫離情境、純套公式的題目，附生活情境改寫方向 |
| 📐 **測驗品質** | 綜合難易度常態性、鑑別度（能否區分高低成就）、信度（錯字／歧義造成的測量誤差）的評述 |

**五大通用審題原則**（每份考卷逐項給「符合／待改善／不符」）：

| 原則 | 檢核重點 |
|---|---|
| ① 目標與範圍一致性 | 範圍合宜（無超綱）、權重合理（配分符合節數比重） |
| ② 題幹與選項規範性 | 語意明確、否定詞標示、誘答有效、答案分布隨機 |
| ③ 素養與情境合理性 | 情境真實合理、圖表清晰且為解題必要 |
| ④ 版面與閱讀友善度 | 字體字距／注音、排版順暢、作答空間充足 |
| ⑤ 份量與難易度配置 | 時間充裕（40 分鐘內）、由易到難建立信心 |

**各科專屬重點**：國語（文字精確、閱讀理解）· 數學（親自驗算、數字合理、解法包容）· 英語（目標文法、情境真實、聽力品質）· 社會（時空正確、價值中立、圖表判讀）· 自然（概念精確、實驗變因、安全現象）· 生活（圖畫注音、跨領域整合、題意簡單）。

**📋 匯出審題紀錄檢核表**：每份考卷審完後可一鍵匯出獨立的 HTML 檢核表（可列印／存 PDF），內含「實務審題四輪流程」（試解對答案 → 雙向細目表對照 → 逐題微觀審查 → 回饋與溝通）、五大原則判定、審查發現、難易度與命題建議，並附命題／審題教師簽核欄，供回饋存查。

## 🫀 健康預測 App（LifeSpan）

檔案：`health.html`（單一 HTML，瀏覽器直接開啟，或部署至 GitHub Pages）

一套個人健康管理與延壽輔助系統，功能包含：

| 功能 | 說明 |
|---|---|
| 📊 綜合健康評分 | 整合心血管、身體組成、活動、飲食、睡眠、菸酒、心理、代謝 8 大面向 |
| ⏳ 生理年齡預測 | 依生活型態因子估算「身體年齡」與實際年齡的落差 |
| 🕰️ 預期壽命推估 | 基於實證流行病學因子估算壽命區間與「可再爭取的年數」 |
| 🔬 慢性病風險 | 心血管疾病、第二型糖尿病、代謝症候群 相對風險分級 |
| 📈 趨勢追蹤 | 儲存紀錄點，追蹤體重、血壓、血糖、健康分、生理年齡變化 |
| ✅ 每日習慣 | 喝水、運動、蔬果、睡眠等每日打卡與連續天數 |
| 💡 延壽行動清單 | 依影響程度排序的個人化建議（附預估延壽年數） |
| 🤖 AI 健康顧問 | 選填：接 Gemini / OpenAI 取得更詳細個人化建議 |

**預測模型**整合 BMI、腰高比、血壓、靜止心率、血糖/血脂、運動量、睡眠、飲食品質、吸菸、飲酒、壓力與家族病史等因子，採用 Mifflin-St Jeor 基礎代謝公式與 FINDRISC 風格風險積分。

### 🔗 資料串接（匯入）

系統可自動解析並帶入外部健康資料，全程在瀏覽器端完成、資料不外傳：

| 來源 | 檔案格式 | 自動擷取 |
|---|---|---|
| 🏥 **健康存摺**（My Health Bank） | FHIR Bundle / JSON | 血壓、血糖、糖化血色素、總膽固醇、HDL、體重、身高、心率（依 LOINC 代碼對應） |
| ⌚ **穿戴裝置** | Apple 健康 `export.xml` / Google Fit JSON | 每日步數→每週運動量、靜止心率、睡眠時數 |
| 📎 **現有 App / 附件** | JSON / CSV | 依欄位名（含中英文）自動對應各項檢驗值 |

> **關於健保：** 台灣全民健保基於資安設計，未開放第三方 App 直接讀取個人資料。正確且合法的流程是由本人到「健保快易通／健康存摺」匯出自己的資料後於此匯入 — 系統不會、也無法繞過此步驟直連健保伺服器。

### 🚨 智慧預警：主動思考的健康系統

不只被動計分，而是像臨床「早期預警」概念一樣**主動分析趨勢、預測未來、提出最佳方案**（設計參考 [Fasten Health](https://github.com/fastenhealth/fasten-onprem)、[HealthLog](https://github.com/MBombeck/HealthLog) 的 proactive check-ins，與 wearable early-warning score 研究「趨勢比絕對值更能提前預測惡化」的結論）：

| 能力 | 說明 |
|---|---|
| 🛎️ **主動警示** | 結合「現值危險門檻」與「惡化趨勢偵測」，分三級（🔴立即注意／🟠需改善／🟡趨勢留意），每項附原因與建議行動 |
| 🔮 **未來走向預測** | 對體重、BMI、血壓、血糖、健康分、生理年齡做線性外推，估算「依此趨勢，約 N 個月後將跨越危險門檻」 |
| 🎯 **最佳方案模擬器** | 勾選願意採取的行動（戒菸、運動、減重、控壓、控糖…），即時重算健康分／生理年齡／預期壽命，量化每項效益並找出最佳組合 |
| 🤖 **每日自動守護** | 後台每日自動用同一套引擎檢查最新數據，偵測到危險門檻或惡化趨勢就**主動寄 Email 警告**（無警示則不打擾） |
| ✨ **AI 守護解讀** | 將警示與健康摘要交給 AI（Gemini/OpenAI），產生同理、個人化的解讀與本週行動計畫；App 內可即時產生，後台自動信也會附上 |

> 設計理念：讓健康系統從「你來查」變成「它來提醒你」——主動思考、提前預警、給出可執行的最佳解。

### ☁️ 雲端後台與自動化（`health-backend.gs`）

以 Google Apps Script + 試算表作為個人健康資料的雲端中心：

- **儲存**：每次評估的快照存入「健康紀錄」工作表；匯入的檢驗值存入「檢驗匯入」。
- **比對**：後台自動比較最近兩次紀錄，回傳各指標的變化與「改善/退步」判定。
- **管理**：跨裝置雲端同步（上傳全部 / 從雲端拉取合併）。
- **自動化**：
  - 執行一次 `setupWeeklyTrigger()` 後，系統每週一早上 8 點自動產生**健康週報**（含趨勢比較與久未量測提醒），寄送 Email 並存檔於「健康週報」工作表。
  - 執行一次 `setupDailyWatch()` 後，系統**每日**早上 9 點自動執行警示引擎（`evaluateAlerts`），偵測到危險門檻或惡化趨勢才主動寄警告信（含當日去重，無警示則不打擾）。
  - **AI 個人化解讀（選填）**：執行一次 `setAiConfig('gemini','你的KEY')`（或 `'openai','sk-...'`），金鑰存於 Script Properties、不寫死於程式碼；之後每日守護信與每週週報都會附上 AI 生成的同理解讀與本週行動計畫。

設定：開啟 Google 試算表 → 擴充功能 → Apps Script → 貼上 `health-backend.gs` → 執行 `setupWeeklyTrigger()` 授權 → 部署為網頁應用程式（執行身分：我；存取：所有人）→ 複製網址貼入 App「設定 → 雲端後台」→ 測試連線。前端以 `text/plain` POST 避免 CORS 預檢，可穩定直連。

> ⚠️ **免責聲明**：所有預測皆為基於公開流行病學研究的統計估算，僅供衛教與自我管理參考，**不能取代醫療診斷**。如有健康疑慮，請諮詢合格醫師。

隱私：所有資料僅存於瀏覽器 `localStorage`；AI Key 僅存本機、直接呼叫 API，不經第三方伺服器。
